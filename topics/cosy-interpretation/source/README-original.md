# COSY 读谱 · 从一张幻灯片数出 14 个峰 —— 交互教学页

把一张教学幻灯片（"COSY – interpretation and use cases" + 一张 calculated COSY 图）
做成**能动手核对**的页面：左栏一步步问、中栏立刻变、右栏告诉你现在看到的是什么。

- **主题**：怎么读一张 COSY（相关谱）；这张图上到底有多少个峰、它们说明什么、又漏掉了什么
- **读者水平**：大学课程初学者（学过 ¹H NMR，刚接触 2D NMR）
- **目标**：自己能数出一张 COSY 上有几个峰，并说清它**给不了**什么信息

## 页面结构（为什么这样排）

- **工作台（三栏各自滚动）**：左「步骤 + 参数 + 候选分子」、中「骨架 / 2D 谱 / 反相双峰剖面」、右「读数 + 分子解剖 + 峰清单」。
  工作台高度 = 视口高度 − 顶部，所以**拖参数时图永远在同一屏**；三栏各自 `overflow-y:auto`。≤1080px 退化为纵向流式。
- **7 步引导**：每步只有三样东西——一个问题、一个要做的操作、点「看答案」才展开的结论。
  **切到某一步会自动把参数设成该步要展示的状态**（例如第 5 步自动把 C=O 换成 –CH₂–，方块数 16→19），也可以自己手动改，两者不冲突。
- **每个数字都挂来源徽章**：<span>原图</span> / <span>文献近似</span> / <span>理论计数</span> / <span>模型参数</span> / <span>计算</span>。
- **术语自动加注**：正文里 77 处术语带虚线下划线，悬停弹中英文解释；「术语与官能团速查」集中列一遍。
- **长内容全部折叠**：原始材料与像素核对、完整归属表、术语速查、推导与数值核对、8 条常见误区、来源与限制 + 页面自检。

## 三个数值内核

### 1) 耦合图内核（组合，可枚举）

    顶点 = 有氢的碳；边 = 有耦合的两个位点
    对角峰 = V 个，交叉峰 = 2E 个（(a,b) 与 (b,a) 成对），独立峰 = V + E
    一条 m 个位点的链：方块数 = 3m − 2
    片段数 = 耦合图的连通分量数

| 情形 | 位点 | 边 | 片段 | 方块 | 原图实测 |
|---|---|---|---|---|---|
| 乙基丁基酮（骨架读数，本页默认） | 6 | 4 | 2 | **14** | 14 ✓ |
| 乙基丙基酮（原文标题所说） | 5 | 3 | 2 | 11 | ✗ |
| 假想 C=O→CH₂（链不断） | 7 | 6 | 1 | 19 | — |
| 无氢分子 / 单一位点 / 两自旋 | 0 / 1 / 2 | 0 / 0 / 1 | — | 0 / 1 / 4 | 平凡情形 |

### 2) 反相双峰可见性内核（COSY 特有）

交叉峰在两个方向都是**反相**的：正负两瓣间距 = J，面积相等 ⇒ 积分恒为 0。

    D(ν) = L(ν − J/2) − L(ν + J/2),   L 为半高半宽 γ = Δν₁/₂/2 的洛伦兹
    ν*   = (Δν₁/₂/2)·sqrt[(x² − 1 + 2·sqrt(x⁴+x²+1))/3],  x = J/Δν₁/₂
    V_snr(x) = x/√(1+x²)          （匹配滤波信噪比，相对 J→∞ 的极限）
    V_height(x) = 4x√w² / [w⁴ + 2w²(1−x²) + (x²+1)²]

**只有比值 x = J/Δν₁/₂ 决定可见性**（尺度不变性）。典型值：³J = 7.3 Hz、Δν = 1.5 Hz
⇒ x = 4.87、V_snr = 0.980（清清楚楚）；跨羰基 ⁴J = 0.5 Hz ⇒ x = 0.33、V_snr = 0.316（看不见）。

### 3) 两自旋密度矩阵模拟（独立实现，验证上面的物理来源）

90°–t₁–β–检测，H = Ω₁I₁z + Ω₂I₂z + 2πJ(I₁·I₂)，2D FFT 取峰。
结论：交叉峰随 β 先增后减、在 90° 最强；对角峰随 β 减小、过 90° 后反号。
（**踩过的坑**：位移取 800/1100 Hz 而谱宽只有 1/dt = 500 Hz ⇒ 折叠，四个"峰"幅度完全相同。）

## 与原图的关系：逐像素测量

标定（两次独立读数）：

| 轴 | 刻度像素 | px/ppm | 0 ppm 位置 | 拟合残差 |
|---|---|---|---|---|
| F2（上投影 + 横轴） | 969.5, 1041.5, 1114.5, 1187.0, 1259.5, 1332.5, 1404.0 | −145.04 | x = 1404.48 | ≤ 0.54 px（0.004 ppm） |
| F1（左投影 + 纵轴） | 399.5, 451.5, 503.5, 555.0, 606.5, 658.5, 710.5 | +103.57 | y = 399.64 | ≤ 0.29 px（0.003 ppm） |

于是量出：

- **14 个峰方块** = 6 个对角 + 8 个交叉（4 对镜像）；方块是固定画法（绿晕 + 深红内核），尺寸只差几像素
- **6 个位移**（两条 1D 投影各自独立读出，最大差 0.011 ppm）：0.901 / 0.988 / 1.290 / 1.565 / 2.336 / 2.420 ppm
- **4 对耦合**：0.90↔1.29、1.29↔1.57、1.57↔2.42、0.99↔2.34
- **骨架 5 个转折顶点 + 2 个端甲基标签 + 1 个羰基氧**，键长 24–38 px

### 一个必须说明的矛盾（本页不替原文掩饰）

原文第三条要点写的是 "two fragments – ethyl and propyl"（乙基 + 丙基 ⇒ 5 个氢环境 ⇒ 11 个方块），
但按骨架顶点数读出来是**乙基 + 丁基**（7 个碳），而且图上实测的是 **6 个氢环境 + 4 对耦合 = 14 个方块**：
**图本身和"乙基 + 丁基"自洽，和标题文字不自洽。** 本页默认按骨架读数走，同时在左栏给了「乙基丙基酮」按钮，
一点就能看到它预测的 11 个方块与实测 14 个对不上。

## 开发过程中被抓到的真错误

1. **`m.J4` 未定义**：`buildModel()` 返回的对象里没带 `J4`，`drawStruct` 一取 `m.J4[0]` 就抛
   `Cannot read properties of undefined`，于是 **2D 谱整块空白、右栏读数全空**，页顶出现红条。
   ——只有「注入 window.onerror 后截图再亲眼看」才抓得到；命令退出码照样是 0。
2. **官能团卡从来没渲染**：`renderGCards()` 定义了但没有一处调用它，「分子解剖」永远是空的。
   交互测试 `T20 六张官能团卡 :: n=0` 直接抓到。
3. **羰基换成 –CH₂– 后 4J 边没删**：方块数变成 21（应为 19）——新链穿过那个碳了，跨羰基那条边就该消失。
   测试断言「第 5 步 ⇒ 19 行」抓到。
4. **`syncUI()` 里重画步骤面板**：每改一次参数就把 7 个步骤按钮全部重建 —— 键盘焦点会丢，测试里"点过的按钮引用"也会失效。
   改成只在 `gotoStep()` / 看答案时重画。
5. **步骤切换没把状态设全**：从第 5 步回到第 3 步时 `ch2` 还开着，题面说的图和实际画的对不上。
   现在每一步的 `ap()` 都显式给全状态。
6. **F1 轴标定方向写反**：刻度数组按 y 从小到大配了 3.0→0，于是 F1 的 ppm 全反号，
   所有峰都被判成"交叉峰"、0 对成对。修好后 4 对交叉峰闭合误差 ≤ 0.056 ppm。
7. **V_snr 归一化漏了 √2**：闭式与数值积分差 0.41。第一性推导 ∫D² = (1/πγ)·a²/(γ²+a²)、
   ∫L² = 1/(2πγ)，分母要用 J→∞ 的极限 2∫L² 归一，才让 x→∞ 时 V→1。改完偏差降到 1.1e−16。
8. **1D 投影峰检测用"上包络"会漏峰**：2.42 与 2.34 只差 12 px，包络法把矮的那个吞掉了。
   换成"暗度剖面（扣基线）"后两条投影都稳定给出 6 个峰，且互相差 ≤ 0.011 ppm。
9. **密度矩阵模拟里谱宽折叠**（见上）：四个"峰"幅度完全相同 —— 位移必须落在 ±SW/2 内。

## 数据来源与限制

1. 原图只是一张教学幻灯片，**不含任何实测谱数据**；页内 2D 谱由模型计算，已标"示意"。
2. δ 是原图像素估读值（±0.02 ppm），J 是文献常见近似值（±0.5 Hz）：
   原图峰宽约 0.05 ppm（≈7 Hz），压根量不出 J，也没有任何多重峰结构可读。
3. 1D 投影用一阶（弱耦合）多重峰 + 洛伦兹线型，Hz→ppm 按 400 MHz 换算（模型参数）；
   真实的二级效应、屋顶效应、溶剂效应都不建模。
4. 可见性阈值 0.5 是**显示判据**，不是自然常数；真实谱"看不看得见"还取决于噪声、对角峰尾巴、采集时间。
5. 「假想 C=O→CH₂」只是教学开关（会变成庚烷），位移用模型值。
6. 没有真实实验曲线可以对照：本页只能核对**模型内部自洽性**（闭式解、渐近、不变量、两套实现互拍）
   与**原图读数**（标定残差、两次独立读数一致性），不能核对"与谱仪输出一致"。
