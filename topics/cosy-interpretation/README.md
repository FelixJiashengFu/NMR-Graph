# COSY 解读：从一张幻灯片核对峰数

[打开离线交互页](./index.html) · [查看整页预览](./preview.png)

本专题沿用户提供的 COSY 幻灯片读图：图中可数出六个对角峰标记和四对交叉峰标记，共 14 个位置。页面可联动查看原图、像素核对图、峰表和候选骨架，并演示弱耦合峰为何可能低于显示阈值。

## 证据边界

- 14 个位置来自教学幻灯片上的图形标记，不是原始 FID 或实测谱的重新处理结果。六个化学位移为像素估读。
- 幻灯片文字说“乙基 + 丙基”，而画出的骨架与 14 个位置支持“乙基 + 丁基”；页面保留两种候选，说明这处不一致。
- 页面中的耦合常数、峰形、线宽、可见性和“将 C=O 换成 CH₂”都是近似或教学模型，不代表原图提供的实验参数。

## 文件与重建

- `index.html`：独立离线网页，内含原图、核对图、脚本和 20 个 KaTeX 公式字体。
- `preview.png`：整页预览。
- `source/`：原图、像素测量结果、可编辑模板、构建脚本、数值核验与交互检查；`source/README-original.md` 保留随附的项目说明。
- 在 `source/` 目录运行 `python3 _build.py` 可重建上层 `index.html`，所需 KaTeX 资源已放在 `source/vendor/`。
