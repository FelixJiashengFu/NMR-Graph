# ¹H–¹⁵N HMBC：齐拉西酮降解产物教学页

[打开交互教学页](./index.html)。`index.html` 是单文件离线网页，已内嵌样式、脚本和原始幻灯片截图；原文件名为 `ziprasidone_hmbc_teaching.html`。

页面用一张课程幻灯片讲解 ¹H–¹⁵N HMBC 的交叉峰、氮轴上的负化学位移及齐拉西酮相关结构的判读。可切换结构单元、查看原图放大区域、逐项查看估读峰位。

| 路径 | 内容 |
| --- | --- |
| `index.html` | 可直接打开的交互网页 |
| `preview.png` | 整页预览 |
| `src/` | 可编辑源码、构建脚本及未修改的原图 |
| `verify/` | 数据与页面核验脚本、随原文件提供的截图 |

原图没有提供峰归属或实验条件。页面重建的谱图和峰位是从截图估读的，结构归属属于辅助推断；不要将它们当作原始实验数据。

在本目录运行 `python src/build.py` 可从源码重新生成 `index.html`。
