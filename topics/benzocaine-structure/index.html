01　四步拼接结构

第一步 / 不饱和度

DBE = 5

一个苯环贡献 4；一个羰基贡献 1。分子式与“芳环 + C=O”相容。

第二步 / 乙基

q（2H）+ t（3H）

共同 J ≈ 7.2 Hz 支持 CH₂CH₃。CH₂ 在约 4.32 ppm，碳在 60.5 ppm，支持 OCH₂。

第三步 / 芳环

2H + 2H

四个芳氢分成两组；芳环碳也只有四种环境。这强烈支持对位二取代芳环。

第四步 / 氨基与酯

NH₂ + CO₂Et

4.04 ppm 宽峰归给 NH₂；166.9 ppm 归给酯羰基。两者放在芳环对位，解释全部计数。

\mathrm{DBE}=\frac{2C+2+N-H-X}{2}=\frac{2\times9+2+1-11}{2}=5

O 不出现在 DBE 公式里；这里没有卤素，X = 0。

哪张谱更容易先读？ 本题从 ¹H 更容易先发现“乙基”和“两组各 2H 的芳氢”；¹³C APT 则更适合检查碳的类型和对称性。两张谱合起来，归属才完整。

\delta_q=\frac{2157.8\ \mathrm{Hz}}{500\ \mathrm{MHz}}=4.3156\ \mathrm{ppm}

三重峰原图读数 / Hz

687.2 → 680.1 → 672.9

\delta_t=\frac{680.0667\ \mathrm{Hz}}{500\ \mathrm{MHz}}\approx1.3601\ \mathrm{ppm}

这里采用图中频率相对于化学位移参考的标注。Hz 是频率差，ppm 是归一化化学位移；在 500 MHz 仪器上，7.2 Hz 对应 0.0144 ppm。

\Delta\delta\ (\mathrm{ppm})=\frac{J\ (\mathrm{Hz})}{\nu_0\ (\mathrm{MHz})}=\frac{7.2}{500}=0.0144

04　三个容易读错的地方

APT 上下方向是本图的相位约定

APT 区分的是两组：CH / CH₃ 与 Cq / CH₂。整体相位翻转后，所有峰都上下颠倒，但分组关系保持不变。向上不能单独证明一个碳就是 Cq，因为 CH₂ 也向上。

NH₂ 的宽峰积分不一定正好等于 2

氢交换、峰变宽和积分范围都会影响读数。这里将原图 1.6 保留为观测值，结构仍计 2H。截图没有 D₂O 交换实验，不能把它说成已经做过的确认。

芳香区不能机械套 n + 1

对位二取代芳环可出现 AA′BB′ 耦合体系，常表现为两个表观双峰。截图没有芳香区精细放大，因此不计算其精确 J，也不把示意峰形当作真实谱线重建。
