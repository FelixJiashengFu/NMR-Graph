两种实验回答不同问题

COSY 对照：A–B 与 B–C 有直接近邻耦合。TOCSY：两条通路串联后，A–C 也有接力相关。TOCSY 的 A–C 峰不能单独证明 A 与 C 直接相邻。

04 / 直观解释：传递像沿网络接力

把氢组视为节点，有效标量 J 耦合视为连接。A 先与 B 相连，B 再与 C 相连；TOCSY 混合期间的传递可沿这条耦合网络继续传播。因此两个端点同属一个自旋系统。这里没有使用空间距离证据；空间邻近相关应与 NOESY 等实验区分。

STEP 1

标出三个位置

A = CH₂OH，B = 中间 CH₂，C = CH₃。先按氢环境分组，不能把每个 H 都当作独立峰位。

STEP 2

连接直接耦合

主要近邻通路 A ↔ B ↔ C。COSY 对照以这两对为重点；弱长程耦合不在本示意中。

STEP 3

补上接力相关

A → B → C，所以添加 A–C 以及镜像 C–A。操作“看 A → C 接力”并拖动 τ 比较。

STEP 4

对称地完成谱图

三个对角峰先定位，再画 A–B、B–C、A–C 三对交叉峰。最后单独说明 OH 的条件。

05 / 分步推理与数值核对

从一对相关到两个坐标

例如 A–C 的两个峰中心位于 (δA, δC) 与 (δC, δA)。默认示意值为 (3.60, 0.90) 与 (0.90, 3.60) ppm。前者横轴读 A，纵轴读 C；对角峰 A–A 则位于 (3.60, 3.60) ppm。

一组含 n 个可分辨氢环境且所有两两相关均可见时，总计 n² 个峰中心。三组得到 3² = 9；包含 OH 的四组理想完整系统则为 4² = 16。若 OH 独立，则为 3² + 1² = 10；若 A–B 与 C 分开，则为 2² + 1² = 5。每个独立峰对在对角线两侧各贡献一个中心。

这是理想相关位置计数，不保证实验中各峰都可检出；忽略重叠、分辨率、多重峰分裂、伪峰与弱传递。不同系统的理想总数为各组大小平方之和。

演示内核：图扩散类比，不是量子自旋动力学

W 是等权、无向的邻接矩阵，D 为节点度数对角矩阵。τ 无量纲；从某个节点出发的一单位示意“份额”随 τ 扩散。权重守恒、矩阵对称、断开的节点间权重恒为零。模型中每个氢组按一个节点处理，未按 2 / 2 / 3 的氢数加权。

当 τ = 0，PAC = 0；τ = 1 时约为 0.15769；τ = 3 时约为 0.30846。τ 很小时，直接通路 PAB 约为 τ，而两步通路 PAC 约为 τ² / 2，因此端点传递在类比中出现较慢。

采用均匀化级数计算矩阵指数，并用上式独立对拍。页面自检检查零进程、断路、对称、非负与行和为 1，数值容差 10⁻¹²。真实 TOCSY 受 J 值、偏置、射频、弛豫和交换影响，可能出现振荡或长混合时衰减；本扩散类比不能预测实际峰强或“最佳混合时间”。

06 / 常见误区与 OH 条件

“只有相邻碳上的氢才出现 TOCSY 相关”

这会漏画 A–C。TOCSY 的作用是追踪可连续传递的自旋系统；A–C 可以通过 B 接力。

“在同一个分子里，所以全部氢必然相关”

同属一个分子不保证连续有效耦合。OH 可能因快速交换而表现为独立信号，也可能宽化或消失；若交换足够慢且 OH–A 耦合与传递有效，才可把 D 接入链。页面的慢交换选项是明确的条件假设。

“9 个峰 = 9 个氢；交叉峰强度能直接当积分”

9 是三种共振的二维坐标中心数，分子仍有 8 个氢。峰强受实验参数影响；这里的扩散权重也不是 2∶2∶3 氢数。

“没有画出来，就证明没有耦合”

提高阈值可以隐藏接力峰，但路径仍存在。实验缺峰还可能来自传递效率、混合时间、重叠或信噪比；不能仅据缺峰断言结构断开。
