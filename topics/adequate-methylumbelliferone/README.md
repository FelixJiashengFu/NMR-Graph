# 1,1-ADEQUATE · 4-甲基伞形酮

页面从用户提供的 ADEQUATE 课件截图提取 a、b、c、e、f 五个质子组的字母标注，重绘 14 个交叉峰关系。可点击质子列、碳行或单个峰，并阅读逐步判读和 f 列示范。原截图已嵌入 HTML，方便对照。

**范围：**这是标注关系的教学示意，不是从原始 NMR 数据生成的谱图。峰位和峰强度不应用作定量或最终结构归属；直接连接的 H–C 归属还需由 HSQC 等实验核实。
