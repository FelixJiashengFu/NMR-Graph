# 正丙醇 TOCSY：自旋混合模型与画谱练习

[打开离线交互页](./index.html) · [查看整页预览](./preview.png)

本专题根据正丙醇 TOCSY 练习题截图制作，展示四组质子（含可选的 OH）、耦合网络、混合时间与二维相关峰的联动。可切换 OH 参与条件、COSY 对照、化学位移和混合时间。页面含离线 KaTeX 字体与原始截图，可单独下载打开。

与库中已有的[正丙醇 TOCSY 基础专题](../tocsy-propanol/index.html)相比，这一页使用理想各向同性混合的四自旋矩阵模型，展示随混合时间变化的磁化转移。两个专题采用不同的教学近似，分别保留。

## 来源与边界

- 原图仅有题目和结构式，没有实测谱图、化学位移、耦合常数或实验条件。
- 页面内的谱图与峰强是模型示意；默认 δ、J、T₁ρ 和谱仪频率为教学参数或文献近似，不是这张截图的测量值。
- OH 是否进入耦合网络取决于交换等实验条件。关闭 OH 参与时，页面将其从网格移除；真实实验中它仍可能出现对角峰。
- 详细参数、公式、验证记录及模型限制见[原项目说明](./source/README-original.md)。

## 文件

原项目的重建脚本还依赖其说明中提到的 KaTeX 包目录；已发布的 `index.html` 不需要该构建依赖。
