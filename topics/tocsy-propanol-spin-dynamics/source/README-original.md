# TOCSY · 正丙醇 —— 一步步推断（交互教学页）

把一张只有两行字的练习题截图（"Draw the TOCSY spectrum expected from n-propanol"）
做成**能动手推的页面**：左栏一步步问、中栏立刻变、右栏告诉你现在看到的是什么。

- **主题**：TOCSY（全相关谱）用于正丙醇时会给出什么样的二维谱
- **读者水平**：大学课程初学者（学过 ¹H NMR，刚接触 2D NMR）
- **目标**：自己推出「2D 谱上有几个峰」，并说清「什么时候会少」

## 页面结构（为什么这样排）

- **工作台（三栏各自滚动）**：左「步骤 + 参数」、中「图」、右「读数 + 官能团卡」。
  工作台高度 = 视口高度 − 顶部，所以**改参数时图一定在同一屏**，不需要来回滚动页面。
  三栏各自有独立滚动条（`.col{overflow-y:auto}`），互不干扰。
  `≤1240px` 自动退化为普通纵向流式布局（手机上不需要嵌套滚动区）。
- **每一步一个落脚点**：左上角是 7 步引导，每步只做三件事——
  抛一个问题、给一个要做的操作、点「看答案」才展开结论。
  **切到某一步会自动把参数设成该步要展示的状态**（例如第 5 步自动取消 –OH，第 6 步自动开 COSY），
  也可以自己手动改参数，两者不冲突。
- **所有化学名词都配图配注**：右栏「分子解剖」给每个官能团画了显式画出每个氢的小结构图，
  外加氢数 / δ / 耦合对象 / 多重峰 / 原图对应色块；正文里 20 多个术语自动加虚线下划线，
  悬停弹出解释；「术语与官能团速查」把全部词条和它们的图集中列一遍。
- **长内容全部折叠**：原图、完整归属表、速查、推导、误区、来源与自检都在 `<details>` 里，默认收起。

## 数值内核：各向同性混合的精确解

    H    = 2π Σ_{i<j} J_ij ( Iix Ijx + Iiy Ijy + Iiz Ijz )     [角频率单位]
    U(t) = exp(−i H t)
    M_jk(t) = Tr(I_jz U I_kz U†) / Tr(I_kz²)
            = (1/2^{N−2}) Σ_{a,b} ζ_j(a) ζ_k(b) |U_ab|² ,   ζ_j(a) = ±1/2

- **Python 侧**：16 维复矩阵 + `numpy.linalg.eigh`。
- **JS 侧**：16 维实对称矩阵 + 手写 Jacobi 特征分解（**两套互相独立的实现**）。
- 两套在 τ=80 ms 的 4×4 矩阵上逐元素对拍，最大偏差 **4.5 × 10⁻⁷**（只来自 Jacobi 收敛阈值）。

### 不变量（页内「来源与限制 + 页面自检」实时显示，全部通过）

| 检查项 | 结果 |
|---|---|
| 零耦合 / τ=0 / 单自旋 ⇒ 单位阵 | 偏差 0 ～ 3.1 × 10⁻¹⁶ |
| 磁化守恒 Σ_j M_jk = 1 | 偏差 2.2 × 10⁻¹⁶ |
| 矩阵对称 M_jk = M_kj | 偏差 1.7 × 10⁻¹⁶ |
| 两自旋闭式解 M₁₂ = sin²(πJτ) | 偏差 5.6 × 10⁻¹⁷ |
| 极大点 τ = 1/(2J) = 71.4286 ms | 数值 71.43 ms |
| –OH 去耦后交叉项泄漏 = 0 | 0 |
| C3 –CH₃ 三重峰 1:2:1 | 3 线，比例 1:2:1 |

### 关键结论的数值依据

τ_m = 80 ms、阈值 0.05 时 4×4 矩阵 16 个元**最小值 0.0679**（≈ 阈值的 1.36 倍）⇒ 满格 16/16。
τ_m = 25 ms 时只剩 10/16。关闭 –OH 后 3×3 满格 9/9。COSY 对照模式 10/16。
n=4 时独立峰 = 4（对角）+ C(4,2)=6（交叉对）= 10，方块数 = 4² = 16。

## 开发过程中被抓到的六个真错误

1. **哈密顿量多了一个因子 2**：τ 极大值变成理论值的 5 倍，两自旋闭式解偏差高达 1.0。
   曲线"长得像 sin²"完全掩盖了它——只有把「极大必须落在 1/(2J)」当成**可证否的判据**才逼出来。
2. **`makeJ()` 没做下标越界保护**：构造 1 自旋 / 2 自旋体系时抛
   `Cannot set properties of undefined`，被 Node 侧自检抓到。
3. **LaTeX 里的裸 `<` 被 HTML 解析器吃掉**：`\sum_{i<j}` 里的 `<j` 被当成标签开头，
   整条公式没渲染还搅乱了后文。改用 `&lt;`（`textContent` 会还原），并加了「正文裸 `<` 必须为 0」的扫描。
4. **`<!--KATEX_JS-->` 占位符漏写**：构建脚本 `replace` 了空气、还报告"无残留占位符"，
   公式全以原始 LaTeX 显示。**靠亲眼看截图**才发现。构建脚本现在先断言占位符存在。
5. **步骤切换后 UI 不刷新**：`gotoStep()` 调了 `applyState()` 就走了 `else` 分支，
   `renderStep()` 从未执行——参数确实变了，但题面还停在第一步。交互测试直接抓到。
6. **缓存键用了过期的 `EIGKEY`**：`curM()` 先拼键再调 `curEig()`，
   于是「改了耦合配置但 τ 没变」时会撞上上一次的缓存，静默拿到**旧自旋体系的矩阵**——
   表现是切到第 6 步少了 2 个方块。`curEig()` 提到拼键之前即可；`curves()` 同样处理。
   （这类错误曲线照样画得出来，只有断言"该有几个方块"才抓得住。）

## 数据来源与限制

1. 原图只是练习题幻灯片，**不含任何实测谱数据**。页内 2D 谱由模型计算，已标注"示意"。
2. δ 与 J 是文献典型近似值（δ ±0.05 ppm、J ±0.5 Hz 量级）；页面 ppm 读数给到 0.01 只为滑块连续，
   **那个小数位没有实验意义**。
3. 模型简化：分组自旋（磁等价）近似、理想各向同性混合、只算 z 磁化在位分数
   （不建模反相分量与 TOE 伪峰）、弛豫用单一 e^(−τ/T₁ρ) 因子、忽略 NOE/ROE、
   1D 投影用一阶多重峰 + 洛伦兹线型（FWHM 1.5 Hz）。
4. –OH 的处理有真实的实验歧义：取消勾选时本页把 –OH **整个移出**自旋体系（网格退化为 3×3）；
   真实谱里 –OH 的对角峰往往仍在（宽单峰），但不会有交叉峰。两种画法对"哪些交叉峰存在"结论一致。
5. 没有真实实验曲线可以对照，本页只能核对**模型内部自洽性**（守恒、对称、闭式解、两套实现互拍）
   与**组合计数**，不能核对"与谱仪输出一致"。

### 两个测量陷阱（都真实踩到了）

- **Chrome 无头窗口最小宽度约 500 px**。直接 `--window-size=390` 拿到的其实是 500 px 视口，
  截图只截 390 px，会被**误判成"手机端横向被裁"**。正确做法：把页面塞进 390 px 宽的 iframe 截图，
  或在页内直接比较 `clientWidth` 与 `scrollWidth`。
- **`--dump-dom` 模式下 `requestAnimationFrame` 可能完全不触发**，页面会停在初始状态、测试得到一片假失败。
  页面里的统一刷新因此加了 `setTimeout` 兜底，测试也一律用 `setTimeout` 等待。
