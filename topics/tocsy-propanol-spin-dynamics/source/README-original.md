# TOCSY 练习题 · 正丙醇 —— 交互可视化讲解

把一张只有两行字的练习题截图（"Draw the TOCSY spectrum expected from n-propanol"）
拆成**可验证的物理模型 + 可操作的图形 + 可核对的数字**。

- **主题**：TOCSY（全相关谱）用于正丙醇时会给出什么样的二维谱
- **读者水平**：大学课程初学者（已学过 ¹H NMR 与化学位移，刚接触 2D NMR）
- **一句话目标**：能从「自旋体系的连通性」推导出峰图样，并说清羟基氢那唯一的岔路口

## 数值内核：各向同性混合的精确解

理想 TOCSY 的自旋锁定等价于各向同性混合：

    H    = 2π Σ_{i<j} J_ij ( Iix Ijx + Iiy Ijy + Iiz Ijz )     [角频率单位]
    U(t) = exp(−i H t)
    M_jk(t) = Tr(I_jz U I_kz U†) / Tr(I_kz²)
            = (1/2^{N−2}) Σ_{a,b} ζ_j(a) ζ_k(b) |U_ab|² ,   ζ_j(a) = ±1/2

- **Python 侧**：16 维复矩阵直接构造 + `numpy.linalg.eigh`。
- **JS 侧**：16 维实对称矩阵 + 手写 Jacobi 特征分解（**两套互相独立的实现**）。
- 两套实现在 τ=80 ms 的 4×4 矩阵上逐元素对拍，最大偏差 **4.5 × 10⁻⁷**
  （只来自 Jacobi 收敛阈值；页面显示的 3 位小数完全稳定）。

### 平凡情形与不变量（页内「页面自检」面板实时显示，全部通过）

| 检查项 | 结果 |
|---|---|
| 零耦合 ⇒ 单位阵 | 偏差 0 |
| τ = 0 ⇒ 单位阵 | 偏差 3.1 × 10⁻¹⁶ |
| 单自旋 ⇒ 单位阵 | 偏差 0 |
| 磁化守恒 Σ_j M_jk = 1 | 偏差 2.2 × 10⁻¹⁶ |
| 矩阵对称 M_jk = M_kj | 偏差 1.7 × 10⁻¹⁶ |
| 两自旋闭式解 M₁₂ = sin²(πJτ) | 偏差 5.6 × 10⁻¹⁷ |
| 极大点 τ = 1/(2J) = 71.4286 ms | 数值 71.43 ms |
| –OH 去耦后交叉项泄漏 = 0 | 0 |
| C3 –CH₃ 三重峰 1:2:1 | 3 线，比例 1:2:1 |

### 关键结论的数值依据

τ_m = 80 ms、阈值 0.05 时，4×4 矩阵 16 个元**最小值 0.0679**（≈ 阈值的 1.36 倍）
⇒ 满格 16/16 可见。τ_m = 25 ms 时只剩 10/16。关闭 –OH 后 3×3 满格 9/9。
n=4 时独立峰 = 4（对角）+ C(4,2)=6（交叉对）= 10，方块数 = 4² = 16。

## 开发过程中被抓到的四个真错误

1. **哈密顿量多了一个因子 2**（写成 `H = 2π·2J(I·I)`）：τ 极大值变成理论值的 5 倍，
   两自旋闭式解偏差高达 1.0。曲线"长得像 sin²"完全掩盖了它——只有把
   "极大必须落在 1/(2J)" 当成**可证否的判据**才把它逼出来。
2. **`makeJ()` 没做下标越界保护**：构造 1 自旋 / 2 自旋体系时抛
   `Cannot set properties of undefined`，被 Node 侧自检直接抓到。
3. **LaTeX 里的裸 `<` 被 HTML 解析器吃掉**：`\sum_{i<j}` 里的 `<j` 被当成标签开头，
   哈密顿量那一条公式整段没有渲染，还顺带把后面的正文一起搅乱。修法是写成 `&lt;`
   （`textContent` 会还原成 `<`，KaTeX 拿到的仍是正确源码）。构建流程现在多了一道
   「正文中裸 `<` 数量必须为 0」的扫描。
4. **`<!--KATEX_JS-->` 占位符漏写**：构建脚本 `replace` 了空气、还照样报告"无残留占位符"，
   于是公式全部以原始 LaTeX 显示。这是**靠亲眼看截图**发现的——所以构建脚本现在
   会先断言占位符存在，且验收必须"注入 window.onerror 后截图 + read_image 亲眼看"。

## 数据来源与限制

1. 原图只是练习题幻灯片，**不含任何实测谱数据**。页内 2D 谱由模型计算，已明确标注"示意"。
2. δ 与 J 是文献典型近似值，随溶剂/浓度/温度漂移（δ ±0.05 ppm、J ±0.5 Hz 量级）。
   页面 ppm 读数给到 0.01 ppm，**那个小数位没有实验意义**，只为滑块连续可调。
3. 模型简化：分组自旋（磁等价）近似、理想各向同性混合、只算 z 磁化在位分数
   （不建模反相分量与 TOE 伪峰）、弛豫用单一 e^(−τ/T₁ρ) 因子、忽略 NOE/ROE 通路、
   1D 投影用一阶多重峰 + 洛伦兹线型（FWHM 1.5 Hz）。
4. –OH 的处理有真实的实验歧义：本页取消勾选时把 –OH **整个移出**自旋体系
   （网格退化为 3×3）；真实谱里 –OH 的对角峰往往仍在（宽单峰），但不会有交叉峰。
   两种画法对"哪些交叉峰存在"的结论一致。
5. 没有真实实验曲线可以对照，因此本页只能核对**模型内部的自洽性**
   （守恒、对称、闭式解、两套实现互拍）与**组合计数**，不能核对"与谱仪输出一致"。

### 两个测量陷阱（都真实踩到了）

- **Chrome 无头窗口最小宽度约 500 px**。直接 `--window-size=390` 拿到的其实是 500 px 视口，
  截图只截 390 px，会被**误判成"手机端横向被裁"**。正确做法：把页面塞进 390 px 宽的 iframe 截图，
  或在页内直接比较 `clientWidth` 与 `scrollWidth`。
- **`--dump-dom` 模式下 `requestAnimationFrame` 可能完全不触发**，页面会停在初始状态，
  测试会得到一片假失败。页面里的统一刷新因此加了 `setTimeout` 兜底，测试也一律用 `setTimeout` 等待。
