# ¹H–¹⁵N HMBC 与 HSQC 教学页

打开 [交互教学页](./index.html)。页面为可离线打开的单文件网页；[整页预览](./preview.png)供快速查看。

这个专题并列解读两张课程截图：齐拉西酮降解产物的 ¹H–¹⁵N HMBC，以及磷酸化蛋白的 ¹H–¹⁵N HSQC。前者展示小分子中的氮环境和长程相关，后者展示蛋白残基的单键相关与磷酸化后的位移变化。它与仓库中的[齐拉西酮 HMBC 专题](../hmbc-ziprasidone-degradation/index.html)是两份独立教学页。

原材料仅为两张截图，没有原始谱图数据、完整实验条件或逐峰归属。页面将原图直接可见的信息、按坐标轴估读的数值、结构辅助推断和演示模型分开标识。两图的 ¹⁵N 参考标度可能不同，不应直接比较其原始 ppm 数值。具体估读精度与限制见页面开头的“读前必读”。

`assets/` 保存未经改动的两张课程原图；`src/` 保存可编辑源码和构建脚本；`verify/` 保存图像测量、静态核验及原项目的浏览器核验记录。`package.json` 提供构建与核验命令。
