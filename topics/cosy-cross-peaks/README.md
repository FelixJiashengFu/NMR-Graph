# COSY：交叉峰从哪来、什么时候会少

[打开离线交互页](./index.html) · [查看整页预览](./preview.png)

这份中文教学页从用户提供的 COSY 幻灯片出发，解释直接耦合产生的交叉峰，并用正丙醇演示混合时间、阈值、位移重合和 OH 交换对可见峰的影响。页面提供七步引导、二维示意谱、联动读数和来源说明。

## 证据范围

- 原图提供结构、文字提示和示意色块；没有实测谱数据、可靠刻度、化学位移、耦合常数或采集参数。色块大小不能当作峰强。
- 正丙醇的峰位、峰形、强度与 OH 交换曲线是教学模型或近似参数，不是原图恢复出的实验谱。
- 完整四位点近邻链的 10 格、关闭 OH 后的 7 格等是给定模型下的理论计数；真实可见峰仍取决于实验条件。
