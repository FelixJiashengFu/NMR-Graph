01

主要结论

先给答案，再看推导

不能仅用 ADEQUATE 完成全部碳归属：有 2 个碳（C13、C15）不会出现在 ADEQUATE 的 ¹³C 维， 另有 4 个环碳因对称性化学等价、无法彼此区分。

  1. 原图的结论性文字只有两句问题原图观测： "We could assign this compound using INADEQUATE, is the same possible with ADEQUATE?" 与 "Are all the carbons in this compound assignable using ADEQUATE?"。原图并未给出答案。
  2. 两类实验给出同一类信息，但入口不同。INADEQUATE 直接在 ¹³C 通道检测， 只要两个碳直接相连就能形成相关，不要求带氢； ADEQUATE 是 ¹H 检测，相关对中至少有一个碳要带氢，代价是 下仍需两个相邻 ¹³C，但灵敏度高得多。
  3. 本分子恰好踩到两个盲区理论计数： C15（甲氧基）被氧隔断，没有任何 C–C 键，INADEQUATE 和 ADEQUATE 都拿不到它的 C–C 相关； C13（苄位 CH₂）两侧的 C4、C14 都是， 没有 可用， 因此在 1,1-ADEQUATE 的 ¹³C 维不出现。
  4. 对称性限制与实验无关结构辅助推断：对位二取代苯环存在一个包含两个取代基的 ， 使 C2≡C6、C3≡C5 成为 碳： 4 个环 CH 只给 2 个信号，任何实验都无法把它们分开。
  5. 要"全部归属"，必须联用。用 补齐 C13、C15 的碳位移，用 的 ³J 相关确认 OCH₃ 与羰基的连接。 ADEQUATE 的价值在于确定碳骨架的连接顺序（14 根 C–C 键全部可见），而不是独自包办所有碳。

04

分步推理

从结构到结论的六步

  1. 读骨架：确定取代模式与连接顺序 原图观测

    苯环为 1,4-二取代。上取代基（连 C1）为 –CH(CH₂OH)–CH₂–CH(CH₃)–CH₃； 下取代基（连 C4）为 –CH₂–C(=O)–O–CH₃。两个取代基所连的环碳 C1、C4 是 。 逐键读出的连接关系是本页一切推理的起点。

  2. 数碳并分类 理论计数

    共 15 个碳：CH₃ 3 个（C11、C12、C15）、CH₂ 3 个（C7、C9、C13）、 CH 6 个（C2、C3、C5、C6、C8、C10）、季碳 3 个（C1、C4、C14）。 校验：3 + 3 + 6 + 3 = 15。实测中这一分类可直接由 给出。

  3. 找对称性，合并等价碳 结构辅助推断

    对位二取代苯环有一个包含 C1–C4 轴与两个取代基的镜面，交换 C2↔C6、C3↔C5。 故 4 个环 CH 碳只给出 2 个信号。独立 ¹³C 信号数 = 15 − 2 = 13。

  4. 列出全部 C–C 键 理论计数

    芳环内 6 根，侧链 6 根（C1–C8、C8–C7、C8–C9、C9–C10、C10–C11、C10–C12）， 酯端 2 根（C4–C13、C13–C14），合计 14 根 C–C 键。 另有 4 根 C–O 键（C7–O1、C14=O2、C14–O3、O3–C15）不参与 ¹J(CC)。

  5. 按实验规则逐碳判定 理论计数

    INADEQUATE：只要该碳有 C–C 键就出现在 ¹³C 维 → 只有 C15 不出现。

    1,1-ADEQUATE：该碳要有一个"带氢的邻接碳"才作为被相关碳出现。

    逐碳检查：C1（邻 C2/C6/C8，均带氢）✓；C4（邻 C3/C5/C13）✓；C14（邻 C13）✓； C13（邻 C4、C14，均为季碳）✗；C15（无 C–C 键）✗。其余皆 ✓。

  6. 汇总并回答原图两问 理论计数

    问 1（ADEQUATE 能否像 INADEQUATE 一样归属）：不能完全等同。 INADEQUATE 的 ¹³C 维含 14 个碳，1,1-ADEQUATE 只含 13 个，差额正是 C13。

    问 2（是否所有碳都可归属）：否。C15 对两种实验都不可见； C13 在 ADEQUATE 中不出现；C2/C6 与 C3/C5 因等价无法区分。 完成全部需 HSQC + HMBC 配合。

自检关系：质子化碳 + 季碳 = 碳原子总数（12 + 3 = 15）； 独立信号 = 碳原子总数 − 等价重复（15 − 2 = 13）； C–C 键数 = 环内 6 + 侧链 6 + 酯端 2 = 14。

6.2 分子式与不饱和度 理论计数

按骨架推得的分子式为 C₁₅H₂₂O₃（氢数逐碳相加：2+2+3+1+2+1+3+3+2+3 = 22）。

Ω = (2C + 2 + N − H − X) / 2 = (2×15 + 2 + 0 − 22 − 0) / 2 = 10 / 2 = 5 // 苯环 4 + 羰基 1 = 5 ✓
M = 15×12.011 + 22×1.008 + 3×15.999 = 180.165 + 22.176 + 47.997 ≈ 250.34 g·mol⁻¹

注意：分子式由本页从骨架推出，原图并未给出，属 结构辅助推断；若原图另有说明，应以原图为准。

6.3 天然丰度与成对概率 理论计数

¹³C 天然丰度 a ≈ 1.1%。需要两个相邻 ¹³C 的实验，成对概率为：

P = a² = (0.011)² = 1.21 × 10⁻⁴ ≈ 1 / 8 300 // 若富集到 10%，P = 1% ；富集到 100%，P = 1

这正是 INADEQUATE 需要近乎纯样品、而 ADEQUATE 靠 ¹H 检测把门槛降到数十毫克量级的原因。 拖动左侧"¹³C 富集度"滑块可看到该概率的平方级变化。

6.4 转移效率模型 演示模型

实验的固定延迟 Δ 按设定的 值调谐：Δ = 1/(4·J_set)。对真实耦合为 J_actual 的键，双量子激发效率按正弦平方变化：

E(J_actual) = sin²( π · J_actual · Δ ) ， Δ = 1 / (4 · J_set)

当 J_set = 55 Hz 时：芳环键（57 Hz）E ≈ 50%；sp³–sp³ 键（34 Hz）E ≈ 22%。 也就是说，单一 J_set 无法同时兼顾芳环与烷基链，链上相关峰会明显偏弱。 把滑块拉到 34 Hz，烷基链变亮、芳环变暗，可直观看到这一权衡。

6.5 边界与不变关系

  • 简单情形：若分子中所有碳都带氢且不含杂原子，则 INADEQUATE 与 1,1-ADEQUATE 的 ¹³C 维包含完全相同的碳集合，信息等价。
  • 边界情形 1：把 ¹³C 富集度设为 100%，成对概率 P = 1，灵敏度不再是瓶颈， 此时"看不见某个碳"就纯粹是连接性问题（C13、C15），而非统计问题。
  • 边界情形 2：把 J_set 设成该键的真实 ¹J(CC)，该键效率达到模型最大值 50%； 偏离越远效率越低，但不会改变"该碳是否出现在 ¹³C 维"这一连接性判定。
  • 应保持不变的关系：无论怎么调滑块、切实验，以下三项都不应改变 —— 碳原子总数 15、季碳数 3、独立信号数 13。它们只由结构决定。
07

常见误区

五条最容易踩的坑
✗ 误区 1：ADEQUATE 是 ¹H 检测，所以完全看不到季碳。
✓ 准确说法：相关对中只要有一个碳带氢即可。

1,1-ADEQUATE 关联的是"直接相连的两个碳 + 其中一个碳上的氢"。因此季碳只要邻接带氢碳， 仍然会出现在 ¹³C 维。本分子中 C1、C4、C14 三个季碳都能出现，正是因为它们分别邻接 C2/C6/C8、 C3/C5/C13、C13。

✗ 误区 2：ADEQUATE 与 INADEQUATE 完全等价，可以互相替代。
✓ 准确说法：信息类型相同，但覆盖范围可以不同。

二者都给"相邻碳连接"，但在"两侧都没有氢"的碳上 ADEQUATE 会丢失信息。 本分子的 C13 就是例子：它与 C4、C14 之间的键在 INADEQUATE 里看得见，在 1,1-ADEQUATE 里看不到。

✗ 误区 3：只要实验做得够久，所有碳最终都能被 ADEQUATE 看到。
✓ 准确说法：连接性盲区靠延长时间无法弥补。

C15 被氧与碳骨架隔断，根本没有 ¹J(CC) 可用；再多的扫描次数也不会凭空产生一根不存在的键。 这类碳必须换实验（HSQC 读位移、HMBC 读 ²J/³J 连接）。这正是 所描述的情形。

✗ 误区 4：对位苯环的四个 CH 碳可以分别归属。
✓ 准确说法：C2≡C6、C3≡C5 化学等价，任何实验都分不开。

这是分子对称性造成的，与用哪种脉冲序列无关。归属报告中应写成 "δ 129.0（C2/C6）"这样的合并归属，而不是硬分给某一个碳。

✗ 误区 5：本页的谱图与化学位移来自原图。
✓ 准确说法：原图没有任何谱图数据，全部为演示模型。

本页的 δC 数值取自文献典型值，示意谱、效率曲线与灵敏度指数均为教学演示， 不得作为该化合物的实验数据引用。

9.2 理论依据

  • Columbia University NMR Core Facility · ADEQUATE —— "1,1-ADEQUATE correlates two directly bonded carbons with a proton directly bonded to one of the carbons"， 并说明天然丰度下仅约 0.01% 的分子被观测到。 https://nmr.chem.columbia.edu/content/adequate
  • UCL NMR · ADEQUATE —— m,n-ADEQUATE 经 mJ(CH) 与 nJ(CC) 给出碳–氢化学位移相关； "the observation of all 1,1-ADEQUATE cross-peaks provides the same type of information as INADEQUATE"； 并提示杂原子过多时需注意 Crews 规则。 https://www.ucl.ac.uk/nmr/nmr-experiments/adequate
  • Hebrew University (HUJI) · 2D ADEQUATE —— 脉冲序列延迟 Δ = 1/(4J(CH))、1/(4J(CC))； ¹J(CC) 单键约 35–45 Hz、双键约 65 Hz；F1 维为两个相关碳的双量子频率之和。 https://chem.ch.huji.ac.il/nmr/techniques/2d/adequate/adequate.html
  • New variants of the ADEQUATE experiments（Saurí 等，Elsevier） —— 天然丰度下两个 ¹³C 同时出现的概率约 1:10 000；ADEQUATE 可给出与季碳相关的信息， 常与 HMBC/LR-HSQMBC 互补使用。 https://www.sciencedirect.com/science/article/pii/S0066410319300122
