从一张 NMR 幻灯片（标题 *ADEQUATE* + 两句英文问题 + 一个分子骨架）出发，
判定 **1,1-ADEQUATE 能否归属该化合物中的全部碳原子**，并说明哪些碳必须借助其他实验。

## 2. 网页讲了什么

页面按 **主要结论 → 直观解释 → 分步推理 → 数值核对 → 常见误区 → 来源与限制** 组织，
另含「原图核对」「完整归属表」「术语表与官能团」。

**核心结论**：不能仅用 ADEQUATE 完成全部碳归属。

| 判定 | 结果 |
|---|---|
| 碳原子总数 | 15 |
| 季碳（C1、C4、C14） | 3 个 |
| 独立 ¹³C 信号 | 13 个（C2≡C6、C3≡C5 化学等价） |
| INADEQUATE ¹³C 维可见 | 14 个碳（唯一盲区 C15） |
| 1,1-ADEQUATE ¹³C 维可见 | 13 个碳（盲区 C13、C15） |
| 分子式 / 不饱和度 | C₁₅H₂₂O₃ / Ω = 5 |

两个盲区的成因：

* **C15（甲氧基）** 被氧与碳骨架隔断，**没有任何 C–C 键** → 缺少 ¹J(CC)，
  INADEQUATE 与 ADEQUATE 都拿不到它的 C–C 相关。
* **C13（苄位 CH₂）** 两侧的 C4、C14 **都是季碳** → 没有可用的 ¹J(CH)，
  因此它不作为「被相关碳」出现在 1,1-ADEQUATE 的 ¹³C 维。

（注意：季碳本身**并不是**盲区。1,1-ADEQUATE 关联的是「直接相连的两个碳 + 其中一个碳上的氢」，
所以 C1、C4、C14 只要邻接带氢碳就能出现。这一点被单列为常见误区 1。）

## 6. 哪些数据无法从原材料确认

原始材料只有一张幻灯片截图，**没有**任何谱图、峰位、化学位移或实验条件。因此：

**可以确认**：标题 `ADEQUATE`；两句英文问题（逐字转录）；分子骨架的连接关系与原子标注
（`H₃C`、`CH₃`、`OH`、`O`）；苯环的凯库勒式画法；两个取代基处于对位（1,4-二取代）。

**无法确认**：化合物名称、分子式、任何化学位移数值、谱图与峰位、以及实验条件
（溶剂、磁场强度、探头、浓度、扫描次数、¹J(CC) 设定值）。

**页面中属于「演示模型」的内容**（均已标注，非实测数据）：
* 全部 δC 数值（取文献典型值，仅示意峰位）
* 信号条长度与转移效率曲线（`E = sin²(π·J·Δ)` 教学简化式）
* 相对信号强度指数（以 1,1-ADEQUATE + 天然丰度 + J = 55 Hz 为 100）
* 分子式与分子量（由骨架推得，原图未给出）

**理论依据**（页面第 9 节列出完整出处）：
Columbia NMR Core Facility、UCL NMR、Hebrew University (HUJI) 2D ADEQUATE 页面，
以及 Saurí 等《New variants of the ADEQUATE experiments》。
