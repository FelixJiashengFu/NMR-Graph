# 数圈 · 牵绳 · 合围（幅角原理 → 儒歇定理 → 用留数计算实积分）

水墨风格的复变函数自学页。双击 `index.html` 即可打开：样式、脚本、公式和公式字体都已内嵌在这一个文件里。两种中文字体（马善政毛笔楷书、思源宋体）从 Google Fonts 加载，断网时退回系统的楷体和宋体，内容不受影响。

这一页不是从课件截图做的，没有原图。内容是教材里的标准定理和证明，图是为讲解画的，图上的数是浏览器现算的。

## 页面讲什么

- **引**：留数是什么，为什么绕一圈只留下 1/(z − a) 的系数；留数定理；三条算留数的公式。
- **圈**：幅角原理。从留数看（对数导数 f′/f 把零点和极点变成单极点），从几何看（像曲线绕原点的圈数）。
- **绳**：儒歇定理。遛狗的说法，四步证明，连续形变的看法；例题 z⁵ + 3z + 1 的根的分布；推论代数基本定理。
- **围**：用留数算实积分，四型各一例：三角型、有理型、含 e^{iax} 型（若尔当引理）、路上有极点（小半圆绕开）。
- **练**：六道小题，答案可展开。
- **析**：分析注释总表，29 条。

## “意思”注释

正文里凡是用到数学分析的地方（极限、连续、一致收敛、逐项积分、最值定理、介值定理、含参变量积分、反常积分、主值、ML 估计、若尔当不等式等），都配了注释，分两种：

- **朱批**：红字，紧挨着那一步公式，用白话说这一步在做什么、凭什么可以这样做。全页 46 条。
- **术语注释**：带虚线的词可以点，弹出“意思”和“在这里”两段；卷末“析”一节是全部 29 条的总表。

构建脚本会检查：正文里每个可点的术语在总表里都有一条，总表里每一条正文都用到了；对不上就拒绝构建。

## 四个互动图怎么操作

- **留数小图**：选 n，拖 θ 或点“走一圈”。左图是 z 沿单位圆走，右图把每一小步 zⁿdz 首尾相接。只有 n = −1 时停在 2πi，其余都回到 0。
- **幅角原理**：零点（墨点）、极点（红叉）和圆心（小十字）都可以拖；可以添点、删点、改重数、改半径。右图是像曲线 f(C)，下面每个小罗盘记一个因子转了多少。键盘：Tab 选中一个点，方向键移动（按住 Shift 走大步），Delete 删除。
- **儒歇定理**：选多项式，点各项决定哪些归主项 f，拖半径 R。右图把全式除以 f，人在 1，狗在 1 + tg/f，树在 0。“绳长图”是沿圈一周的 |f| 和 |g|，点它可以移动位置。拖 t 看 f + tg 的零点怎样动。
- **围道台**：四型切换。逐段显示数值积分，对照 2πi 乘圈内留数之和；下面的图是实轴段和大弧的贡献随 R 的变化，点它可以改 R。底色的墨色表示 |f(z)| 的大小。

系统设置了“减少动态效果”时，“走一圈”直接跳到终点。页面跟随系统的深色、浅色模式；宽屏双栏，窄屏单栏。

## 哪些是定理，哪些是示意，哪些是数值

| 类别 | 内容 | 说明 |
| --- | --- | --- |
| 定理 | 留数定理、幅角原理、儒歇定理、若尔当引理、小弧引理及各例题的结果 | 教材标准内容，证明思路写在正文里 |
| 示意 | 遛狗的比喻、小罗盘、w 平面的径向压缩、围道台的墨色 | 帮助理解；w 平面按 ln(1 + \|w\|) 压缩径向，方向不变，所以圈数不变；墨色按 log\|f\| 分六层，只表示大小的层次 |
| 数值 | 图上的所有读数 | 浏览器现算：沿围道的积分用复合辛普森公式，多项式的根用 Aberth 迭代，圈数由采样点的幅角增量累加 |

数值有误差，显示到小数点后两位或四位，末位可能不准。零点或极点贴近围道时，页面会提示圈数没有意义；极点正好落在弧上时，围道台不给数。

第四型的图里，墨线是从 ε 到 R 的积分，停在虚线 π/2 下方：0 到 ε 那一小段被挖掉了，要 R → ∞ 和 ε → 0 都取完才到 π/2。

## 仍需注意

- 幅角原理一图里的 f 只限有理函数、围道只限圆；儒歇定理一图只限多项式和以原点为心的圆。定理本身对一般的亚纯函数和简单闭曲线成立。
- 第四型只演示了 sin x / x 一个例子；多值函数的积分（锁眼围道）没有收入。
- 文末的参考书只列了书名和章节，没有逐条对照页码。
- 页面文件约 1.15 MB，大部分是 586 条预先渲染好的公式（同时带 MathML，供读屏软件使用）。
