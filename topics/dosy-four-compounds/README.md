# DOSY：四种化合物的扩散排序

[打开交互教学页](./index.html)。`index.html` 是单文件离线网页，已内嵌样式、脚本和原始幻灯片截图。

页面用一张 DOSY 幻灯片讲解横轴的 ¹H 化学位移、纵轴的扩散系数，以及水、丙酮、胆碱和 TSP 的扩散排序。可选择化合物、调节温度与黏度的演示模型、放大原图，并查看逐点归属。

## 文件

| 路径 | 内容 |
| --- | --- |
| `index.html` | 可直接打开的成品网页（原文件名 `dosy_teaching.html`） |
| `preview.png` | 整页预览 |
| `assets/original_dosy_slide.png` | 原始幻灯片截图 |
| `src/` | 可编辑源码、构建脚本和核验脚本 |
| `verify/` | 数据提取结果、原有核验报告与截图 |

原图没有提供原始谱图数据和实验条件。页面中的化学位移与扩散系数是从截图估读的；半径换算和参数滑块属于演示模型，不能当作实测结果。`verify/verify_report.txt` 是随原文件提供的核验记录。

在本目录运行 `python src/build.py` 可从源码重新生成 `index.html`。
