DOSY 扩散排序谱 · 交互教学页

一句话目标：看懂一张 DOSY 二维谱——横轴是 1H 化学位移、纵轴是扩散系数 D；四种化合物因为分子大小不同，在图上分成四条水平线，分子越大 → 扩散越慢 → D 越小。

01主要结论 Key conclusions

  1. 这是一张 1H–D 的 DOSY 二维谱：横轴 δH 化学位移由 5.0 ppm（左）到 0.0 ppm（右）；纵轴 D 扩散系数由 0（上）到 20（下），单位 10−10 m²·s−1。原图观测
  2. 样品含四种化合物，以颜色区分：■◆ TSP（参照物）蓝、● 胆碱 绿、▲ 丙酮 红、■ 水 黑。原图观测
  3. 每种化合物在自己的 D 值上排成一条水平点列：横坐标随其 1H 化学环境而变，纵坐标（D）保持不变。原图观测
  4. 四种化合物的实测 D（由大到小）：水 15.9 > 丙酮 8.7 > 胆碱 6.4–6.7 > TSP 4.4–4.6（×10−10 m²·s−1）。原图观测
  5. 分子越大 → 扩散越慢 → D 越小。本图纵轴向下递增，所以"在图上越靠上"意味着 D 越小、分子越大——这正是原图那句话的含义。结构辅助推断
  6. 原图顶部一维谱只解析出 4 个明显峰（4.77 / 3.19 / 2.23 / 0.06 ppm），而 DOSY 上共量出 11 个点；两者并非一一对应。原图观测

要点：DOSY 的价值在于——即使一维谱上峰重叠，只要分子大小不同，就能在第二维（扩散系数）上被分开。

02直观解释 Intuition & interactive panel

普通一维 1H 核磁只告诉你"这个氢在什么化学环境"（横轴 δH）。但它不知道这个氢挂在一个小分子还是大分子上。DOSY 补上了第二个维度：让每个信号同时报告"它所在分子跑得多快"，即扩散系数 D。它靠的是脉冲梯度场让信号按扩散快慢衰减，再反演成第二个坐标轴。

可以把它想成一场赛跑：小分子（水）跑得快，D 大；大分子（TSP）跑得慢，D 小。而同一个分子上的所有氢坐在同一条船上，速度完全一样，因此它们在图上必然落在同一条水平线上——横坐标各不相同，纵坐标完全相同。这就是"用扩散把混合物按大小分层"的直观图像。

图中蓝色 内标 TSP 是氘代过的参照物；它的三甲基硅基信号被规定在 0.00 ppm，充当整张图横轴的"零点"。

05分步推理 Step-by-step reasoning

  1. 第 1 步 · 定坐标系。横轴刻度 5.0→0.0 ppm，从左到右递减（核磁习惯）。纵轴刻度 0→20，从上到下递增——这一点极易看错，务必先确认。原图观测
  2. 第 2 步 · 横轴分组。把点按 δH 排列：4.77；4.03 / 3.50 / 3.19；2.91 / 2.22 / 1.78；0.66 / 0.16 / 0.05 / −0.07。可以看出四组化学位移区间。原图观测
  3. 第 3 步 · 纵轴读 D。同一组的点纵坐标几乎相同 → 属于同一分子。原图观测
  4. 第 4 步 · 颜色归属。按原图给出的颜色约定：蓝 = TSP（参照物）、绿 = 胆碱、红 = 丙酮、黑 = 水。结构辅助推断
  5. 第 5 步 · 用结构式验证归属。胆碱 (CH3)3N+–CH2–CH2–OH 是一种季铵盐，有三种不等价的氢：HO–CH2、N–CH2、N(CH3)3，对应图上 3 个绿点；丙酮两个甲基上的 6 个氢是等价氢，只有 1 种氢 → 1 个红点；水只有 1 个黑点。三者完全吻合。结构辅助推断
  6. 第 6 步 · 按 D 排序，对照分子大小。水 (18) > 丙酮 (58) > 胆碱阳离子 (104) > TSP 阴离子 (149) 是分子质量顺序；实测 D 恰好完全反序（15.9 > 8.7 > 6.5 > 4.5）。注意丙酮与 TSP 都含羰基，但羰基碳上不连氢，故都不在 1H 谱上出峰。理论计数 + 原图观测
  7. 第 7 步 · 模型自洽性检验。用 Stokes–Einstein 式把 D 换算成流体力学半径，得到的半径顺序与分子大小顺序一致（0.13 < 0.23 < 0.30 < 0.44 nm），说明数据自洽——但这一步依赖假设的 T 与 η，属于演示模型，不是原图结论。

06数值核对 Numerical verification

6.1 单位换算

1 × 10−10 m²·s−1 = 1 × 10−6 cm²·s−1 = 1 × 10−4 mm²·s−1 // 因为 1 m² = 10⁴ cm² = 10⁶ mm²

横轴单位 ppm 是百万分之一的相对频率偏移，无量纲，与磁场强度无关。所以水的 D ≈ 15.9×10−10 m²·s−1 也可写成 1.59×10−5 cm²·s−1，与文献中 25 °C 纯水的自扩散系数（约 2.3×10−5 cm²·s−1）同量级但偏小——因为本样品是含其它组分的溶液，且原图未给出温度。

6.4 边界与简单情形

  • 最简单情形：只选"水"。它只有 1 个点，D = 15.9，是四者中最大（图上最低）。这与"最小分子扩散最快"一致。
  • 边界情形 1：把演示模型温度拉到最低 273.15 K，模型点整体上移（D 变小），但四条线的先后顺序不变——顺序是不变量。
  • 边界情形 2：把黏度拉到最大 1.60 mPa·s，同样整体上移；拉到 0.60 mPa·s 则整体下移。缩放因子与 1/η 成正比，可逐点验算。
  • 边界情形 3：演示半径 r → 0.10 nm 时预测线跑到图的上方（D 很大）；r → 1.00 nm 时跑到下方（D 很小）。与 D ∝ 1/r 一致。
  • 零假设检验：若把 T 设为 298.15 K、η 设为 1.10 mPa·s，缩放因子必须精确等于 1.000，模型点应与观测点完全重合。页面右下角的计算框会实时显示这个因子。
实时验算 · Stokes–Einstein 半径换算 演示模型

公式：D = kBT / (6πηr)  ⇒  r = kBT / (6πηD)，其中 r 为流体力学半径。假设：球体、稀溶液、无相互作用、η 取当前滑块值。

07常见误区 Common misconceptions

✗ 误区 1：纵轴数值越大表示分子越大。
✓ 正确：相反。D 越大表示扩散越快、分子越小。本图纵轴向下递增，所以"图上位置越高"= D 越小 = 分子越大。这正是原图那句话的依据。
✗ 误区 2：把 DOSY 看成两条独立的一维谱。
✓ 正确：它是一种二维核磁实验，每个点同时携带两个信息（δH, D）。横轴仍来自一维谱，纵轴来自扩散测量。图上方那条一维谱理论上应是二维数据的投影，但本原图两者并不完全对应。
✗ 误区 3：一种化合物在图上只会有一个点。
✓ 正确：分子里有几种不等价的氢，就有几个横坐标。胆碱有 3 种 → 3 个绿点；水只有 1 种 → 1 个黑点。
✗ 误区 4：点越大 = 浓度越高，可以定量。
✓ 正确：本图未提供定量标尺或浓度信息，点的面积不能当作浓度读。要做定量需要另行积分，且需说明实验条件。
✗ 误区 5：可以从图上直接读出分子量。
✓ 正确：DOSY 给出的是扩散系数，不是分子量。换算成尺寸必须引入 Stokes–Einstein 模型，并已知温度与黏度——本原图均未给出，因此只能得到"顺序"，不能得到"绝对值"。
✗ 误区 6：所有蓝色点都属于 TSP。
✓ 正确（谨慎表述）：原图标示蓝色为 TSP。但原图所画的是 TSP-d4，其 1H 只剩三甲基硅基一组氢，理论预期在 ≈0 ppm 附近只有一个信号；而实测蓝色点出现在 ≈2.91、1.78、0.66、0.05 ppm 等多处。2.91 与 1.78 ppm 两处无法从原材料确认归属，标为"待确认"。

限制 · 无法从原材料确认的内容

  • 实验条件缺失：温度、溶剂、黏度、磁场强度（MHz）、脉冲序列、梯度强度与扩散时间 Δ/δ、扫描次数、内标浓度、样品 pH——原图均未给出。因此任何绝对值（半径、分子量、浓度）都无法确定，本页给出的半径一律标注为演示模型。
  • 数值精度：所有 δH、D 均为估读值，非原始数据文件导出。δH 不确定度约 ±0.05 ppm，D 约 ±0.3×10−10 m²·s−1。请勿把本页数字当作实验记录引用。
  • 蓝色点归属待确认：原图所画 TSP-d4 理论预期在 ≈0 ppm 只有一组三甲基硅基信号，而实测蓝点分布在 ≈2.91、1.78、0.66、0.05 ppm 等多处。其中 ≈2.91 ppm 与 ≈1.78 ppm 两点无法从原材料确认归属（原图未说明样品是否含其它组分、TSP 是否完全氘代）。
  • 一维谱与 DOSY 不自洽：原图顶部一维谱仅解析出 4 个峰（4.77 / 3.19 / 2.23 / 0.06 ppm），而 DOSY 上量出 11 个点（胆碱的 3.5、4.0 ppm 峰在一维谱上仅呈现为很弱的肩峰，丙酮的红点在 D 方向呈两个重叠小点）。原图的一维谱不能视为 DOSY 数据的严格投影。
  • 未解析的细节：原图未标注交叉峰、未给噪声水平、未说明是否做了 DOSY 反演（如 CONTIN / 最大熵）；点的形状与面积不携带可解释的定量含义。本页重绘的一维谱条带用洛伦兹线型示意，仅用于呈现原图可见的峰位与相对高度。
  • 本页未做的事：未声称"恢复"了真实实验曲线；页面中的散点图与一维谱条带都是依据原图可见信息重绘的示意图形，不是原始数据。
