05

分步推理

从可见证据走到有限结论

  1. 找到对角线。横纵轴都是 1H 化学位移，单位 ppm；同一信号的自相关落在 f₁ = f₂。
  2. 寻找离开对角线的轮廓。约 9.9/7.3 与 3.8/7.3 ppm 一带能看到较清楚的黄色小峰；对称位置互相核对。
  3. 映射回结构。约 9.9 ppm 与醛氢、约 3.8 ppm 与甲氧基相符；约 7.3 ppm 是芳香氢拥挤区，单一 H 位点无法凭截图完全确认。
  4. 只做可支持的推断。若这些确为 NOE/ROE 相关，相关氢在空间上可能相近；还需采集信息与完整谱图排除重叠、交换等其他解释。

07

数值核对

把“第六次方”变成可检查的比值

σ ∝ r−6→I(r) / I₀ = (r₀ / r)6

在相同实验条件、初始速率近似下，用交叉弛豫速率或经过校正的积分讨论距离依赖。右侧曲线只是设定 r₀ = 3.0 Å 的归一化练习。

r = 3.0 ÅI / I₀ = 1
距离变为 2 倍I / I₀ = 1/64 ≈ 0.0156
距离减半I / I₀ = 64

距离单位相消，因此 I/I₀ 无单位。谱图的 ppm 是化学位移单位，不是空间距离。

08

常见误区

哪些结论不能从这张图直接得到

“峰越亮，就能直接读出 Å 数。”

截图没有积分、参考距离和实验条件。颜色轮廓也可能取决于等高线阈值。

“没看到峰，就一定不近。”

低信噪比、重叠、零交叉区和实验设置都可能让相关不明显。

“有交叉峰，就一定是直接 NOE。”

化学交换、间接转移与自旋扩散可能产生或改变相关，需结合实验设计核查。

“NOESY 和 ROESY 可按同一峰相位判读。”

两种实验的转移与相位判读有区别；本截图没有给出相位说明。
