# C₄H₈O₂：¹H NMR 推结构与测耦合常数（水墨长卷）

根据用户上传的一张题图制作的水墨风格讲解页。题目：分子式 C₄H₈O₂，CDCl₃ 中测得 ¹H NMR（250.13 MHz），推断结构并测量耦合常数。双击 `index.html` 即可打开，样式和脚本都在这一个文件里。三种字体（马善政毛笔楷书、志莽行书、思源宋体）从 Google Fonts 加载，断网时退回系统的楷体和宋体，内容不受影响。

结论：乙酸乙酯 CH₃COOCH₂CH₃；³J(H,H) = 7.14 Hz，报告为 7.1 Hz。

## 页面讲什么

全页是一幅手卷，分八卷，每卷一个字：

- **观**：按题图标注的谱线频率重画氢谱。三组信号 a（4.14 ppm，四重峰，2H）、b（2.06 ppm，单峰，3H）、c（1.27 ppm，三重峰，3H）。
- **算**：不饱和度 Ω = 1，两个氧，指向酯或羧酸。
- **数**：积分台阶 2 : 3 : 3，共 8H，等于分子式的氢数，所以谱窗外没有遗漏信号。
- **分**：n + 1 规则与帕斯卡三角；裂分树逐个加入邻位质子，并列出每条线对应的邻位自旋组合。
- **量**：从赫兹标注求 J（相邻差值平均 7.144 Hz；外线法 7.143、7.145 Hz）；两组峰 J 相同，说明互为耦合伙伴；Δν/J ≈ 100，是一级谱。
- **位**：化学位移参考带。4.14 ppm 的 CH₂ 只能连在酯氧上，2.06 ppm 的 CH₃ 连在羰基上。
- **辨**：八种 C₄H₈O₂ 异构体的典型氢谱，与实测谱逐条对质。
- **定**：结构式与谱峰联动，给出期刊格式的数据行。

## 怎么操作

- 卷一：按钮或点击谱峰放大某一组；指针在谱上移动时同时读出 δ（ppm）和 ν（Hz）。
- 卷四：切换 a、b、c 三组，“上一步 / 下一步 / 演示全程”逐层画出裂分树。
- 卷五：量尺上点选同一组里的任意两条线，量出间距并按间隔数折算 J；“外线法”一键选最外两条线。滑块把谱仪频率从 60 MHz 调到 1200 MHz，看同一个 J 折合的 ppm 宽度怎样变化。
- 卷七：点选候选异构体，上排实测、下排候选；对不上的信号用朱色画出。
- 卷八：指向结构中的基团或谱中的峰，两边一起亮起。
- 键盘可操作量尺谱线（Tab、Enter 或空格）。系统设置了“减少动态效果”时，动画改为直接切换。页面跟随系统的深色、浅色模式。

δ 一律按 δ = ν ÷ 250.13 计算。像素估读由 `source/measure.py` 完成，结果在 `source/measure.json`：

- 主谱横轴的八条长刻度线（4.5–1.0 ppm）做直线定标，487.1 px/ppm，残差 0.002 ppm。
- 定标检查：由像素算出的四重峰、三重峰中心与由赫兹标注算出的中心相差 0.0016 与 0.0010 ppm，页面声明的位置误差为 ±0.003 ppm。
- 积分台阶取每段橙色曲线左端下平台与右端上平台的高度差；峰高取各线附近最高像素到放大区基线的距离。

`source/build.py` 构建时把正文里写死的 28 处数字和标注、`measure.json` 核对，对不上就拒绝构建。

## 哪些是重绘或推断

- **谱图是重绘，不是原始数据。** 谱线位置按标注频率放置，强度按 1 : 3 : 3 : 1 与 1 : 2 : 1 设定，线型为洛伦兹线，线宽 0.85 Hz 是假设值。积分曲线由这些线解析积分得到。
- **屋顶效应。** 放大区四重峰右侧两线略高、三重峰左侧略高，差别只有几个百分点（约 1–6 px），接近像素读数误差；页面只作为旁证提及。
- **候选异构体的谱。** 卷七的位移、裂分和积分取 CDCl₃ 中的常见文献值（取整到 0.01 ppm），不是同一台谱仪上的实测；棒状谱内各线间距经过放大，只表示形状。
- **化学位移参考带。** 卷六的范围是常见教科书区间的概括，边界因资料而略有出入。
- **卷首远山与谱仪滑块。** 远山轮廓是三组信号展宽后的示意；滑块只按 J 与场强无关来换算 ppm 宽度，没有模拟低场下的二级效应。

## 仍无法从原材料确认

单峰的精确频率（题图未标注）；实验温度、浓度、采样参数和数字分辨率；题图的出处。

