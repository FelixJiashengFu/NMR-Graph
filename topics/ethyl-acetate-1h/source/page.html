算
卷二

算其不饱和度

动笔之前，先从分子式算出少了几对氢。

不饱和度 Ω（也叫双键当量）衡量分子比同碳数的饱和链状分子少了几对氢。对只含 C、H、O 的分子：

Ω = (2C + 2 − H) ÷ 2 = (2×4 + 2 − 8) ÷ 2 = 1

氧是二价原子，插进碳链不改变氢的数目，所以计算时可以忽略。4 个碳的饱和骨架最多容纳 10 个氢，这里只有 8 个，少了一对，即 1 个不饱和度。

1 个不饱和度等于 1 个 π 键或 1 个环。分子里恰有两个氧，最自然的组合是一个 C=O 加一个 O，也就是酯（–COO–）或羧酸（–COOH）。环醚、羟基酮等结构同样满足 Ω = 1，要交给谱图裁决。

饱和 C4 骨架可容纳 10 个 H：实有 8 个（墨点），缺 2 个（朱圈），故 Ω = 1。

  • 酯R–CO–O–R′：乙酸乙酯、丙酸甲酯、甲酸丙酯……
  • 羧酸R–COOH：丁酸、2-甲基丙酸
  • 羟基酮3-羟基-2-丁酮（乙偶姻）
  • 环醚1,4-二氧六环（不饱和度来自环）

卷三

数其氢数

积分曲线的台阶高度，正比于产生该信号的氢原子数目。

题图中三段橙色阶梯就是积分曲线。在原图上用像素量出三段台阶的高度：

以最小台阶为 1，得到 1 : 1.5 : 1.5。出现了半数，于是同乘 2 化成整数：2 : 3 : 3。

2 + 3 + 3 = 8，恰好等于分子式里的 8 个氢。这说明每个氢都已在谱中出现，窗口之外（如 8 ppm 附近的甲酸 H、10–12 ppm 的羧酸 H）没有被遗漏的信号。

注

题图把积分曲线略向左平移，只为不遮挡谱峰。读台阶高度时只看上下两段平台之差，与左右位置无关。

分
卷四

分其裂分

峰的形状，透露了邻居的数目。

相邻碳上的质子（H–C–C–H，相隔三根键）会经由成键电子感知彼此的自旋，这叫自旋–自旋耦合，记作 3J。若一组等价质子有 n 个等价的邻位质子，它的信号就裂分为 n + 1 条线，强度比是帕斯卡三角第 n 行的二项式系数。

为什么是 1 : 3 : 3 : 1

邻位 CH3 的三个质子，各自可取 ↑ 或 ↓ 两种自旋取向，共 23 = 8 种组合。它们在 CH2 处叠加出的局部磁场只有四种取值：三个同向、两同一反、一同两反、三个反向，对应的组合数是 1、3、3、1，正是四条线的强度比。同理，CH2 的两个质子给出 1、2、1 三种组合，使 CH3 成为三重峰。

题图放大区的峰高印证了这一点（以外侧两线均值为 1）：四重峰实测 0.97 : 3.07 : 3.12 : 1.03，三重峰实测 1.02 : 2.10 : 0.98。

从裂分读出连接关系

  • a 四重峰邻位有 3 个 H；自身 2H，所以是一个 CH2 紧挨一个 CH3。
  • c 三重峰邻位有 2 个 H；自身 3H，所以是一个 CH3 紧挨一个 CH2。
  • 互为邻居a 与 c 正好互相解释，合起来是乙基 –CH2–CH3。
  • b 单峰3H 且不裂分：孤立的 CH3，它所连的原子上没有 H，可能是 C=O 或 O。
量
卷五

量其耦合常数

题目的第二问，答案就写在谱线的赫兹标注里。

耦合常数 J 是同一多重峰中相邻两条谱线的间距，必须以赫兹（Hz）表示。J 来自分子内部经由化学键传递的自旋相互作用，与外磁场强弱无关；ppm 则是相对谱仪频率的比值，同一个 J 在不同谱仪上对应的 ppm 间距不同。

ν (Hz) = δ (ppm) × ν0 (MHz)
在本谱仪上：1 ppm = 250.13 Hz

题图已标出每条谱线的频率。表中 Δν 是每条线与上一条线的频率差：

方法一 · 相邻差值取平均

(7.15 + 7.15 + 7.13 + 7.12 + 7.17) ÷ 5 = 7.144 Hz

方法二 · 外侧两线跨度 ÷ 间隔数

四重峰 (1045.29 − 1023.86) ÷ 3 = 7.143 Hz
三重峰 (325.60 − 311.31) ÷ 2 = 7.145 Hz

为什么差值会有 ±0.03 Hz 的起伏

谱线由有限个数据点描出，峰顶位置只能精确到数据点间隔附近，这就是数字分辨率带来的读数误差，并非真实的耦合差别。方法二只用最外侧两条线，单次读数误差被间隔数摊薄，通常更稳。两种方法结果一致，报告到 0.1 Hz 即可：

3J(H,H) = 7.14 Hz ≈ 7.1 Hz

两组多重峰的间距完全相同。耦合是相互的：CH2 被 CH3 以 7.1 Hz 裂分，CH3 也必被 CH2 以同样的 7.1 Hz 裂分。相同的 J，就是谁与谁耦合的指纹。

注

约 7 Hz 是可以自由旋转的 H–C–C–H（例如乙基）三键耦合的典型值。

换一台谱仪试试

J 以 Hz 计，化学位移以 ppm 计，两者都与磁场无关。会变的是多重峰在 ppm 轴上的宽度：谱仪频率越高，同样 7.14 Hz 的间距折合的 ppm 越小，多重峰越紧凑，不同信号越不容易重叠。拖动滑块看看。

Δν/J 远大于 10 时称为一级谱，n + 1 规则和二项式强度比都成立。本题 Δν/J ≈ 716.1 ÷ 7.14 ≈ 100，是很干净的一级谱，Pople 记号中属 A3X2 型（字母在字母表里相距越远，表示位移差相对 J 越大）。若 Δν/J 接近 1，谱线会明显扭曲，就不能再直接按间距读 J。

细看题图放大区还会发现：四重峰右侧两线略高于左侧（外线实测 100 px 对 94 px），三重峰左侧略高于右侧（234 px 对 226 px）。两组峰都微微倾向对方，这是轻微的屋顶效应。差别只有几个百分点，却从侧面印证了二者互相耦合。

位
卷六

定其化学位移

知道了有几个氢、邻居是谁，再看它们住在哪里。

质子周围的电子云越稀薄，受到的屏蔽越弱，信号越往左（低场，δ 大）。电负性强的氧会直接拉走电子；羰基除了吸电子，还有磁各向异性，也使附近质子去屏蔽。下图把常见基团的典型范围画成淡墨带，三条虚线是本题的三组信号。

  • a · 4.14CH2 直接连在氧上，而这个氧又连着羰基：–C(=O)–O–CH2–。只有酯的烷氧基位置会把 CH2 推到 4.1 ppm 左右。普通醚或醇的 –O–CH2– 在 3.4–3.7 ppm；连在羰基碳上的 –CH2–C(=O)– 只在 2.2–2.5 ppm。
  • b · 2.06典型的乙酰基 CH3–C(=O)–，比普通 CH3 低场约 1 ppm。如果这个 CH3 连在氧上（–O–CH3），应出现在 3.6–3.8 ppm。
  • c · 1.27普通烷基 CH3；β 位有氧，所以比 0.9 ppm 略偏低场。

辨其同分异构
