# 蔗糖 TOCSY：从一列相关峰读懂自旋系统

直接用浏览器打开 `index.html`。该文件内嵌原图、裁切图、脚本、KaTeX 0.16.11 与全部必要公式字体，教学内容不需联网。外部来源链接需联网。

## 操作

选择质子、点击结构节点或表格位点，会同步更新示意谱、原图参考列和解释。调节接力步数理解可达关系，切换 COSY 比较直接耦合；峰宽只改变示意峰形。H1′ 快捷按钮演示 C2′ 不带氢的影响。Tab 导航，方向键调整菜单/滑块，Enter/空格激活结构节点。

## 内容与证据

- 基于用户上传课程截图；结构与蔗糖一致，是根据给定结构识别的主题。
- 页面按结论、直观与分步推理、数值核对、误区、来源与限制组织，保留完整截图与文字解读。
- ppm 是截图估读。定位用代表值，不表示精确仪器峰位；CH₂ a/b 合并，未声称恢复实验曲线。
- 14 个碳上氢、8 个 OH、有效近邻网络 7/5/2 氢分组和理想相关坐标数是结构理论计数。
- 步数、对称相关矩阵、高斯峰形为示意，不是混合时间或真实强度。
- 磁场、溶剂、温度、J、混合时间、原始二维矩阵、CH₂ 独立归属与未标强峰身份无法确认。弱长程耦合可能超出简化网络。

## 文件

- `index.html`：完整离线网页，同时可直接编辑。
- `preview.png`：默认状态整页预览。
- `verification.json`：浏览器实际检查结果。
- `source/template.html`：可编辑教学内容、CSS 与 JS。
- `source/original.png`：用户提供的完整课件截图。
- `source/build.py`：自包含构建脚本；依赖 Python 3、Pillow，KaTeX 已附。
- `source/data_check.py`：独立质子级网络与计数核对。
- `source/verify.cjs`：浏览器操作、离线、公式、响应式检查；需要 Playwright 与 Chrome。
- `source/vendor/katex/`：离线公式依赖与 MIT 许可证。

重新构建：`python3 source/build.py`。独立核对：`python3 source/data_check.py`。
浏览器检查：将 `NMR_NODE_MODULES` 指向包含 Playwright 的 `node_modules`，再执行 `node source/verify.cjs`。可用 `NMR_QA_DIR` 指定手机截图目录；默认保存到 `source/qa/`。网页本身不依赖该目录。

## 验证范围

11 个位点逐一选择；步数 0–5；峰宽、两种模式、显示全部、H1′ 跳转、复位；结构与表格点击；Enter/空格；自测答案；原图展开；3 个公式；嵌入图片；1440/1180/768/390/320 px 布局；无外部加载，无浏览器 JS 错误。人工视觉检查桌面整页及两种手机尺寸。
