原材料文字识别与中文解读
  1. “Can be read kind of like an HMBC” → 读取坐标的方法有相似之处；TOCSY 仍是同核 H–H 实验，HMBC 常为异核 H–C 长程相关。
  2. “Drawing a line down any proton signal shows all the protons in an uninterrupted chain” → 沿某个质子信号向下读列，可找出连续耦合网络中的伙伴。实际可见范围受耦合大小、混合条件与信噪比限制，“all”不能当作每次实验必然全显。
  3. “An example is shown in red” → 红圈给出一个读取示例，不是新的元素类型或负相位标记。
  4. “What about 1′?” → 用 H1′ 检查“结构连接”与“连续质子耦合”之间的区别。

04 / 从直观到分步推理

STEP 1 / 先认坐标

一列固定一个质子频率

横坐标选 δi，向下找峰。交叉峰 (δi, δj) 把当前列与另一质子频率联系起来。对角线上的自相关不要算成另一伙伴。

两轴相同，所以通常还会在 (δj, δi) 看到对称伙伴。现实谱的显示阈值与伪峰可破坏表观对称。

STEP 2 / 找接力路径

直接耦合与多步相关

COSY 常用来读有效的直接 J 耦合。TOCSY 在混合期间可把磁化沿 H1 → H2 → H3 → … 继续传递，因此 H1 与 H4 出现相关不要求它们直接相邻。

操作：选择 H1，将步数从 0 调到 5，观察能到达的伙伴；再切为 COSY。

STEP 3 / 遇到 C2′

没有 H2′ 这个接力站

果糖 C1′–C2′–C3′ 的碳骨架相连，但 C2′ 不带氢。H1′ 到 H3′ 的普通连续邻位质子接力缺少中间站。

H1′ 的两个 CH₂ 氢可有同碳耦合；若位移近同或重叠，其相互相关可能藏在对角附近，不能因此称 H1′ 是“一个完全不耦合的氢”。

网络图为什么是 3 组？

按常规强近邻耦合简化：G = H1–H5、H6a/H6b；F = H3′–H5′、H6′a/H6′b；I = H1′a/H1′b。分别有 7、5、2 个碳上氢。

这是对图中蔗糖结构的有效网络推断；不是由截图逐一证实的 14 条独立共振。CH₂ 的两个氢在界面上合并为一个位点。

怎么确认两糖之间的连接？

TOCSY 擅长在残基内分组。葡萄糖 H1 与果糖 C2′ 的糖苷连接通常要结合 HMBC、HSQC、¹³C 谱等证据检查；不能用本页未出现的跨残基 TOCSY 相关当作连接证明。

结构图是课件给出的解释背景；仅凭这一张 TOCSY 截图，不能从零唯一确定蔗糖的全部立体化学。

05 / 数值核对与模型边界

先数氢，再数理想坐标

葡萄糖端 5 × CH + CH₂ = 7 H；果糖端 3 × CH + 2 × CH₂ = 7 H。共 14 个碳上氢。蔗糖另有 8 个 OH 氢，共 22 H；交换氢不纳入本页的简化网络。

N_{\mathrm{ideal}}=7^2+5^2+2^2=78

若每个碳上氢都分辨、每组内所有相关都可见：含 14 个对角坐标、64 个非对角坐标，即 32 对对称相关。

界面合并 CH₂ a/b 后为 6、4、1 个位点，理想有 6² + 4² + 1² = 53 个有序位点组合。重叠与弱转移会进一步减少可辨峰数。这些都不是原谱实测峰数。

ppm、Hz 与像素定位

\Delta\nu\ (\mathrm{Hz})=\Delta\delta\ (\mathrm{ppm})\,\nu_0\ (\mathrm{MHz})

例：用示意定位值 H1 = 5.44、H2 = 3.58 ppm，差值 1.86 ppm。假设 500 MHz 仪器，则为 930 Hz；截图未给磁场，该值仅为单位换算例。

d(i,j)\leq s

模型用最短路径 d 与接力步数 s 决定是否画出峰。0 步只保留对角；1 步保留直接邻居；5 步覆盖本页各有效子系统。无路径的两个位点在任何步数下都不会连通。

峰形使用高斯示意；峰宽只改变绘图。没有 Bloch 方程、相干转移计算、真实 J、弛豫或实验噪声，不能据此拟合混合时间与峰强。

06 / 常见误区与快速自测
“没有交叉峰，所以没有化学键？”
不成立。TOCSY 的转移依赖有效 J 耦合、混合条件、弛豫和检测阈值。碳骨架相连并不保证连续 H–H 接力。
“TOCSY 和 HMBC 是同一种实验？”
读取矩阵的方法相似，核种和转移机制不同。TOCSY 的两个轴都是 ¹H；常规 H–C HMBC 的一个轴是 ¹³C。
“CH₂ 标签 = 一个氢 / 一个峰？”
标签代表一个碳位点，理论上带两个氢；它们可能非等价、分裂、重叠或近等价，不能用标签数量代替积分。
“时间越长，必然看到所有氢？”
不成立。弱耦合瓶颈、离共振效应、弛豫与长混合引入的其他转移都会影响谱。滑块只是可达路径示意。
“3.84 ppm 重叠，就在同一个系统？”
不成立。G-H6 与 F-H6′ 的示意定位值重合，用来体现原图拥挤区域；两者结构与有效接力网络仍分开。
