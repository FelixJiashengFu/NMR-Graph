# ¹H / ¹³C 化学位移分区速查

打开[交互版速查页](./index.html)。这是可离线打开的单文件网页，包含原图的内嵌副本、化学位移分区、结构式和点选联动。

本页帮助读者认识 ¹H 与 ¹³C 的常见化学位移区间。原图是分区示意图，不是真实谱图；页面给出的是区间和教学解释，并非某个样品的精确峰位。部分在原图中被文字遮挡的分区由制作者按常见范围校订，页面将其标为“校订”或“文献近似”。具体峰位仍须结合实验条件和原始谱图判断。

本次收到的附件只有 HTML 网页和一份说明文档，两者都按原样保存；说明文档见 [README-original.md](./README-original.md)。该文档提及的独立原图、预览图、可编辑源码与验证脚本没有随附件提供，因此这些文件未入库。文档中关于原项目验证的记录为附件自述，本次无法复跑对应脚本。
