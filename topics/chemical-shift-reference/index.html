拿到报告怎么读：从 ppm 反推结构的三步

第一步：先数「有没有杂原子」

  • 氢谱里除了 0.5–1.7 就没别的峰 → 基本是纯烃（烷烃 / 环烷）。
  • 出现 3.2–4.2 的峰 → 附近有 O 或 N（C–O / C–N 上的氢）。
  • 出现 9.5–10.0 → 醛氢，几乎可以直接定醛。
  • 出现 10–13 的宽峰 → 羧酸或酚的 O–H（浓度一变位置就飘）。

第二步：在碳谱里找羰基

  • 190–205 → 醛 / 酮。再回氢谱看有没有 9.5–10.0：有 = 醛，没有 = 酮。
  • 165–185 → 酯 / 酰胺 / 羧酸。配 10–13 宽峰 = 羧酸；配 3.6–3.9 单峰 = 酯。
  • 160–165 且无氢谱旁证 → 也可能是酰胺或碳酸酯。

第三步：用「配对」把碳和氢钉在一起

  • δ_C 55–62 的碳 + δ_H 3.3–4.0 的三氢单峰 = 甲氧基（最经典的一对）。
  • δ_C 60–90 出现好几根 + δ_H 3.2–4.2 同样好几组 = 多个 C–O（糖、多元醇、醚链）。
  • δ_C 110–160 成片 + δ_H 6.5–8.5 成片 = 芳环；芳环取代位碳通常被推到 135–160（比 CH 更靠低场）。
  • 一根 δ_C 170 附近 + 一根 δ_C 60 附近 + 一根 δ_H 4.2 附近的 CH → 典型的酯。

一句话：碳谱负责「有哪些基团」，氢谱负责「几个氢、长什么样」，两边对上才算数。只看一边很容易把醚和醇、酮和醛搞混。
