¹H 和 ¹³C NMR 的 ppm 数值意味着什么？

在核磁共振（NMR）中，¹H NMR 和 ¹³C NMR 的 ppm 数值都表示化学位移（Chemical Shift，δ）。

  • ppm 越大：信号越向低场（Downfield）移动，通常说明原子核受到的电子屏蔽越弱。
  • ppm 越小：信号越向高场（Upfield）移动，通常说明原子核受到的电子屏蔽越强。

注意：¹H 和 ¹³C 的 ppm 范围不同，不能直接比较数值大小。

1. ¹H NMR：氢谱的 ppm 代表什么？

¹H δ (ppm)常见氢环境
0.5–2烷基氢（CH₃、CH₂）
2–3靠近羰基、苯环的氢
3–4.5与 O、N 等相连的碳上的氢
4.5–6.5烯烃氢（C=C–H）
6–8.5芳香环氢
9–10醛基氢（–CHO）
10–13羧酸氢（–COOH）

例如，图片中的 ¹H δ ≈ 7.90 ppm，说明这组氢处于典型的芳香环化学环境，并且相对去屏蔽。

2. ¹³C NMR：碳谱的 ppm 代表什么？

¹³C δ (ppm)常见碳环境
0–50饱和烷基碳
50–90与 O、N 等相连的饱和碳
100–150芳香环碳、烯烃碳
150–185酯、酰胺、羧酸等羰基碳
190–220醛、酮羰基碳

图片中的 ¹³C δ = 131.7 ppm，意味着这个碳很可能属于芳香环或其他 sp² 碳环境。结合 ¹H 7.90 ppm，芳香环上的 CH 是合理判断。

3. 为什么同一个位置，H 是 7.90，而 C 是 131.7？

因为测量的是两种不同原子核：

  • ¹H 感受到的是氢核的局部电子环境。
  • ¹³C 感受到的是碳核的局部电子环境。

它们的核磁屏蔽响应及常见化学位移范围都不同。因此，131.7 ppm 并不意味着该碳受到的去屏蔽程度是相连氢的 16.7 倍。

4. 回到你的 NMR 数据

H₂ / H₆ · 酯基侧
¹H δ7.90 ppm
¹³C δ131.7 ppm
¹H 积分1.9 ≈ 2H
推测环境芳香环上的两个等效氢

这组数据可以理解为：两个化学等效的芳香氢具有约 7.90 ppm 的化学位移，它们所连接的碳位于约 131.7 ppm。

重要区别：ppm 不能直接告诉你有多少个氢。¹H 谱中的积分（Integration）才是判断氢原子相对数量的主要依据，而普通 ¹³C 谱的信号强度通常不能直接用来数碳。

做有机结构推断时，建议重点掌握 化学位移 δ、积分 Integration、裂分 Multiplicity、偶合常数 J 四个概念。结合这些信息，才能比较可靠地确定分子结构。

注：化学位移范围为常见经验值，可能因取代基、溶剂、氢键等因素发生变化。示意图为学习用途，并非实测谱图。
